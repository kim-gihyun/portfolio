How to use
1. Pair the glove as a keyboard once (phone Bluetooth settings → TENG-Glove). It types into any app.
2. Open this page and tap Connect → TENG-Glove. It shows which key you're on and the letter it's about to type.
3. Tap a pad repeatedly to step through its letters; pause about 1 s, or tap another pad, to type it. 4 taps on A2 = delete. 4 taps on A8 = next language (English → 한국어 → 中文). Hold A8 1.5 s = enter. Hold A4 1.5 s = cursor mode (↑ ↓ ← → select, back, page ↑/↓); hold A4 again = mouse mode (a pointer: tap to nudge, hold to glide, A4 = click), once more = typing; A6 = typing from either. Hold A2 1.5 s = move the phone's keyboard one language along, if it ever disagrees with the glove.
Tip: use Android split screen to keep this beside WhatsApp, or Chrome menu → Add to Home screen.
