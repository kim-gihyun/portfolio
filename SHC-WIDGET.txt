ASK SHC WEBSITE WIDGET

The floating Ask SHC panel is installed throughout the portfolio website.
The expand button animates into a full-screen chat workspace on the same page,
including the conversation sidebar, New conversation, saved chats and delete
controls. Collapse with the corner button or Escape. Conversations and drafts
are saved in this browser; the same anonymous daily allowance is used in both
views. No new browser tab opens. On phones, the menu opens the chat list.
Previously saved single-widget chats are migrated automatically. Chats from
the separate workers.dev site remain in that origin and are not imported. The Cloudflare service handles the requests;
GitHub Pages serves only the website. API keys are never included in this site.

Privacy and limits
Visitors must accept the notice before chatting. The widget stores its chat and
anonymous browser identifier locally. Its signed access token stays in memory.
Only anonymous consent and usage records go into application analytics; no
question or answer text is centrally stored there. Model providers receive the
question, relevant recent history and document excerpts after consent.
Admin-only documents are excluded. Hidden citations do not make facts secret.
The shared limit is 20 successful generated answers per browser per UTC day
(8 a.m. Hong Kong). Switching devices or clearing browser storage can create a
new anonymous identifier; this is not verified person-level identification.

Development

Open http://localhost:3000

API keys to NEXT_PUBLIC variables or any frontend file.
